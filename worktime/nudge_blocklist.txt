# 免打扰名单
#
# 前台是这个 App 的时候，解锁弹窗和每小时提醒都不出声。
#
# 什么时候需要它：窗口化运行的游戏和视频。因为「有没有窗口铺满屏幕」是自动
# 判的，铺满的能认出来（原生全屏、无边框全屏都认），但**窗口化跑的游戏认不出来**
# ——它跟一个普通窗口长得一样。所以那种往这里加。
#
# 写法：一行一个，写 App 显示的名字（停靠栏/程序坞里那个名字），
#       或者写 bundle id（更稳，不受改名影响）。大小写随便，两边都转小写比。
#       以 # 开头的行是注释。
#
# 改完**立刻生效**，不用重启。菜单展开时也会重新读一次。
#
# 怎么看 bundle id：
#   osascript -e 'id of app "Steam"'
#
# 底下这几条是按常见情况预填的，用不上就删，少了就加。

Steam
IINA
VLC
QuickTime Player
mpv
Epic Games Launcher
Battle.net
PlayCover
